# ts-merge-collections

โปรเจกต์นี้เป็นโปรเจกต์ภาษา TypeScript ที่พัฒนาขึ้นเพื่อจำลองการทำงานของอัลกอริทึมรวมข้อมูล (Merge Algorithm) จากอาเรย์จำนวนเต็ม 3 ตัวเข้าด้วยกันตามเงื่อนไขที่กำหนด โดยมีข้อกำหนดสำคัญคือ **ห้ามใช้ฟังก์ชันจัดเรียงตัวเลขสำเร็จรูป (เช่น ฟังก์ชัน `sort()`)** ในการพัฒนา

## รายละเอียดอัลกอริทึม (Algorithm Description)

ฟังก์ชัน `merge` จะรับคอลเลกชันของจำนวนเต็ม 3 ตัวเข้ามา ได้แก่:
- `collection_1`: เรียงลำดับข้อมูลจาก **น้อยไปมาก** (Ascending)
- `collection_2`: เรียงลำดับข้อมูลจาก **มากไปน้อย** (Descending)
- `collection_3`: เรียงลำดับข้อมูลจาก **น้อยไปมาก** (Ascending)

และให้ผลลัพธ์เป็นอาเรย์ชุดเดียวที่บรรจุข้อมูลทั้งหมดจากทั้ง 3 คอลเลกชัน โดยเรียงลำดับจาก **น้อยไปมาก** (Ascending)

เพื่อให้เป็นไปตามกฎโดยไม่มีการใช้ `sort()` อัลกอริทึมจะใช้วิธี:
1. การวนอ่านค่าใน `collection_1` จากซ้ายไปขวา (ตั้งแต่ดัชนี 0 ถึงดัชนีสุดท้าย)
2. การวนอ่านค่าใน `collection_2` จากขวาไปซ้าย (ตั้งแต่ดัชนีสุดท้ายถอยกลับมาดัชนี 0) เนื่องจากตัวข้อมูลถูกเรียงจากมากไปน้อยอยู่แล้ว การอ่านย้อนกลับจะทำให้เราได้ข้อมูลจากค่าน้อยไปค่ามาก
3. การวนอ่านค่าใน `collection_3` จากซ้ายไปขวา (ตั้งแต่ดัชนี 0 ถึงดัชนีสุดท้าย)
4. เปรียบเทียบข้อมูลปัจจุบันระหว่างคอลเลกชันทั้ง 3 ตัวหาค่าที่น้อยที่สุด (Minimum) จากนั้นนำค่านั้นใส่ในอาเรย์ผลลัพธ์ แล้วเลื่อนตัวชี้ (Pointer) ของคอลเลกชันตัวนั้นไปข้างหน้า ทำเช่นนี้ไปเรื่อย ๆ จนกระทั่งประมวลผลข้อมูลครบทุกตัว

## สิ่งที่ต้องเตรียม (Prerequisites)
- Node.js (แนะนำเวอร์ชัน 14 ขึ้นไป)
- npm (Node Package Manager)

## ขั้นตอนการติดตั้ง (Setup Dependencies)
ดาวน์โหลดและติดตั้งไลบรารีที่จำเป็นสำหรับพัฒนา (TypeScript และ Jest) โดยรันคำสั่งด้านล่างนี้ผ่าน Terminal ที่โฟลเดอร์หลักของโปรเจกต์:

```bash
npm install
```

## วิธีรัน Unit Test (Execute Unit Tests)
โค้ดสำหรับทดสอบเขียนโดยใช้เฟรมเวิร์ก `Jest` สามารถสั่งรันเทสต์ทั้งหมดเพื่อตรวจสอบความถูกต้องของฟังก์ชันได้ดังนี้:

```bash
npm run test
```

## วิธีแปลงโค้ดเป็น JavaScript (Build Code)
หากต้องการแปลงโค้ดภาษา TypeScript ให้ออกมาเป็นภาษา JavaScript (จะถูกเก็บไว้ที่โฟลเดอร์ `dist`):

```bash
npm run build
```
